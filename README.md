# Pattern Finder 🔎

A simple Python program that finds all occurrences of a given pattern inside a text.

## 🚀 Features

- Searches for a pattern in a given text
- Counts the total number of occurrences
- Finds the starting position of each occurrence
- Returns whether the pattern was found
- Uses a simple pattern-matching approach

## 🛠️ Technologies Used

- Python 3
- Strings
- Functions
- Loops
- Lists
- Conditional statements
